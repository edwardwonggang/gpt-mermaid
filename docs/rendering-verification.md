# 箭头、连线和英文排版验收

兼容性页面统一调用修改后的 `GPTMermaid.mount()`。直接挂载数据源，避免浏览器 Mermaid 扩展提前替换代码块。

## 修复机制

| 现象 | 根因 | 修复 |
| --- | --- | --- |
| 尖端后露出线帽、端点脱离节点 | 旧 marker 预留距离和平头/圆头契约不一致 | 恢复布局完整端点，按真实轮廓求交，尖端参考点统一，线端使用 `butt` |
| 三角形比例不一致 | 把 SVG 高宽误当三角形的高底 | 统一 `M 0 0 L 10 4 L 0 8 Z`，沿箭头方向的高为 10，底为 8 |
| 英文移出节点 | 清理部分 transform、同时改锚点会叠加位移 | 实测标题中心，整体平移；保留子变换和属性列 |
| 旅程图文字缺失或看不见 | 白名单删除 `switch` 子树；系列色覆盖文字 | 保留 SVG fallback，继续删除 `foreignObject`，文字单独赋色 |
| 时序序号模糊且左右不对称 | 深灰字叠深灰圆、源激活条边界被当中心 | 白字，按结构化源参与者定位，测量数字实际中心 |
| 胶囊没有在线上 | 上游标签使用线旁坐标，扩大胶囊后仍沿用旧位置 | 按 `data-id` 找所属边，投影到最终路径并避开节点/其它标签 |
| 箭头和出线挤在一起 | 原端口间距小于箭头底宽 | 按节点侧面分配端口，尺寸受两端实际间距限制；兼容实线共享汇入，保留每条逻辑边 |
| 小折弯、自环过小 | 上游端口错位与默认环尺寸未适配新箭头 | 安全范围内拉直短折弯，扩大自环，端口调整后重新检查障碍 |
| C4 深底深字、连线穿框 | 子 tspan 覆盖父文字色；原生 C4 曲线没有避开中间节点 | 按背景亮度选字色，关系按结构化端点绕行，系统边界标题也作为障碍 |
| 长链过长过宽 | 布局器一直沿单轴排列 | 安全切口折返；分支组整体移动，文字不镜像；复杂反馈与子图明确保留原布局 |

## 可重放步骤

在仓库根目录执行：

```sh
npm run build
npm run check
npm test
PLAYWRIGHT_BROWSERS_PATH="$PWD/.ms-playwright" npm run test:e2e
PORT=4174 npm run serve
```

访问 `/demo/compatibility.html`。去重后 101 个样例中 100 个有效样例应成功，1 个故意非法语法用于错误回退。`?suite=base` 只显示 22 个基础样例；`?layout=original` 禁用折返，方便对照。

`test/render-geometry.mjs` 在同一个 E2E 浏览器中检查三角 marker、真实轮廓接触点、标题、ER 属性列、旅程标签和序号。包围盒内点不算贴边；轮廓外侧/内侧采样必须呈现不同填充状态。四个方向的普通/共享箭头另做 64 倍局部像素检查。

`test/layout-quality.mjs` 覆盖流程与 C4 样例：标签中心到所属边距离小于 0.25 SVG 单位、标签不盖节点、路径不穿非目标节点、自环端口及外伸尺寸、C4 文字对比度至少 4.5、共享端点一致。纯逻辑测试另保留三点 L 形和端口整理导致穿框的反例。

证据生成在 `output/playwright/`：`geometry-report.json`、`layout-after/layout-quality.json`、各图 SVG 和 PNG、`sharp-tip-report.json`、`journey-export.png`。另有 `output/e2e-*` 与兼容页桌面/移动截图。`output/`、浏览器缓存不提交。

## 范围与边界

- 验收范围由上述报告与当前测试执行结果确定；渲染数量不能替代布局断言，也不是对任意 Mermaid 输入的穷举证明。
- ER 基数、UML 菱形和接口圆点保留语义形状；三角箭头统一几何。
- 自定义边色保持优先。布局器没有提供端点元数据的未知关系不会被按“最近节点”随意改接。
- 同向同样式实线允许共享末端；虚线相位、不同线型、双向/圈叉端点不能误合并。共享的每条线杆都按主箭头深度裁切。
- 自动折返适用于平坦长链和具有安全切口的连续分支组。反馈、自环、跨层连边、子图或不可分割的大组会保留原布局，并输出 `data-gptm-adaptive` 与原因。阈值约束主轴，不能承诺任意密图都塞进固定矩形。
- 本轮浏览器验收是 Chromium；Safari、Firefox 尚无实测结果。独立库修复不代表 `my-ai-hub` 内旧渲染器已经同步部署。
- 回滚使用 Git 提交恢复源码和 `dist/` 后重新加载页面；无需迁移用户数据。
