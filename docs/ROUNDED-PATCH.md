# Rounded Mermaid patch

The runtime patch is generated by `scripts/apply-patch.mjs` against Mermaid
12.3.0. It:

- converts decision diamonds to rounded rectangles;
- makes rectangle width follow the real text width;
- reduces large default horizontal padding;
- applies a consistent radius to flow and state nodes;
- rounds the joins of polygon shapes without changing their SVG element type;
- adds a `mermaid-decision` class so themes can distinguish decisions.

The patch uses one-shot string anchors and asserts every anchor exactly once. If
Mermaid changes its published bundle, the build fails instead of producing a
silent, subtly broken runtime.

The older hand-written overview remains in
[legacy-patch.md](./legacy-patch.md).
